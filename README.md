# Drengene Games

Små browserspil, vi konkurrerer i. Hvert spil tager max ca. 2 minutter og virker på både telefon og computer.

**Spil dem her:** https://gaardee.github.io/drengene-games/

## Lav et nyt spil

Åbn [PROMPT.md](PROMPT.md), kopiér prompten, udfyld afsnittet **"MIT SPIL"** og send den til Claude.

Claude laver hvert spil på sin egen branch og åbner en pull request. Når PR'en er merget, dukker spillet automatisk op på forsiden. Reglerne står i [CLAUDE.md](CLAUDE.md).
