# Drengene Games

Små browserspil, vi konkurrerer i. Hvert spil tager max ca. 2 minutter og virker på både telefon og computer.

**Spil dem her:** https://gaardee.github.io/drengene-games/

## Lav et nyt spil

Start en Claude Code-session i dette repo, og skriv **"Vi vil lave et nyt spil"**. Claude spørger først, hvem I er, omdøber samtalen med jeres navne og guider jer derefter igennem idé, navn, point, styring, udseende osv. med spørgsmål og forslag.

Vil I hellere skrive det hele selv på forhånd, så brug prompten i [PROMPT.md](PROMPT.md).

Claude laver hvert spil på sin egen branch og åbner en pull request. Når PR'en er merget, dukker spillet automatisk op på forsiden. Reglerne står i [CLAUDE.md](CLAUDE.md).
