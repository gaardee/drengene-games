# Drengene Games

Små browserspil, vi konkurrerer i. Hvert spil tager max ca. 2 minutter og virker på både telefon og computer.

## Lav et nyt spil

Åbn [PROMPT.md](PROMPT.md), kopiér prompten, udfyld afsnittet **"MIT SPIL"** og send den til Claude.

## Spil

- **[🍕 Pizza Party](games/pizza-party/)** – Løb rundt i gymnastiksalen og spis så meget pizza som muligt på 90 sekunder. 1 point pr. stykke, 8 for en hel pizza – men kommer du for tæt på sofaen, prøver de voksne at fange dig!
